# سند - واجهة الويب الأساسية

## نظرة عامة

هذه هي الواجهة الأساسية لتطبيق سند الإسلامي الشامل. تم تصميمها لتكون متجاوبة مع جميع الأجهزة وتدعم اللغة العربية مع اتجاه النص من اليمين لليسار (RTL).

## الميزات الرئيسية

### 🎨 التصميم والواجهة
- **تصميم متجاوب**: يعمل على جميع الأجهزة (هواتف، أجهزة لوحية، أجهزة كمبيوتر)
- **دعم RTL**: دعم كامل للكتابة من اليمين لليسار للغة العربية
- **واجهة أنيقة**: تصميم حديث ومتسق مع المعايير الإسلامية
- **الوضع المظلم**: دعم للوضع المظلم والمضيء
- **خطوط عربية**: استخدام خطوط عربية جميلة ومقروءة

### 🌐 دعم متعدد اللغات
- العربية (الافتراضية)
- الإنجليزية
- الأردية
- التركية
- الفرنسية

### 📱 التصميم المتجاوب
- **XS (< 576px)**: الهواتف الصغيرة
- **SM (576px - 767px)**: الهواتف الكبيرة
- **MD (768px - 991px)**: الأجهزة اللوحية
- **LG (992px - 1199px)**: أجهزة الكمبيوتر الصغيرة
- **XL (≥ 1200px)**: أجهزة الكمبيوتر الكبيرة

### 🔧 التكامل مع الخدمات الخلفية
- **خدمة القرآن**: عرض السور والآيات
- **خدمة الأحاديث**: البحث في الأحاديث النبوية
- **خدمة القصص**: القصص الإسلامية التعليمية
- **خدمة المواقيت**: حساب مواقيت الصلاة
- **المساعد الذكي**: نظام RAG للإجابة على الأسئلة الدينية
- **خدمة البحث**: البحث الدلالي المتقدم

## الأداء والتحسين

### تحسينات مطبقة
- **Lazy Loading**: تحميل المحتوى عند الحاجة
- **Caching**: تخزين مؤقت للبيانات
- **Debouncing**: تأخير البحث لتحسين الأداء
- **Responsive Images**: صور متجاوبة
- **CSS Minification**: ضغط ملفات CSS
- **JavaScript Optimization**: تحسين كود JavaScript

### مقاييس الأداء
- **First Contentful Paint**: < 2 ثانية
- **Largest Contentful Paint**: < 3 ثواني
- **Time to Interactive**: < 4 ثواني
- **Cumulative Layout Shift**: < 0.1

## الدعم والمساعدة

### المشاكل الشائعة
1. **الخطوط لا تظهر بشكل صحيح**: تأكد من تحميل خطوط Google Fonts
2. **RTL لا يعمل**: تحقق من إعداد `dir="rtl"` في HTML
3. **الواجهة لا تستجيب**: تأكد من وجود viewport meta tag
4. **JavaScript لا يعمل**: تحقق من console للأخطاء
